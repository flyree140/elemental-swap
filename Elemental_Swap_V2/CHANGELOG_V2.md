# Elemental Swap V2 重建版改動說明

版本：`2.1.0-regenerated`

## 1. 元素差異化

V1 的元素概念保留，但 V2 讓三個層次都不同：

1. **彈道**：速度、重力、尺寸、穿透／彈牆不同。
2. **命中**：燃燒、冰緩、雷暈、擊退、破甲、濕潤、顯形、詛咒、纏根、吸引。
3. **換位**：爆炸、冰台、連鎖雷、風衝、岩柱、噴泉、治療護盾、相位分身、藤蔓、引力井。

此外加入元素順序連鎖：

- 冰 → 火：熱震
- 水 → 雷：導電暴潮
- 火 → 風：烈風火環
- 岩 → 自然：岩根隆起
- 光 ↔ 影：明暗蝕相
- 引力 → 風：引力彈弓

## 2. 攻擊 / Combo 系統

加入：

- Z 快攻與多段 Command Combo。
- X 重攻。
- Z→Z→X 挑空。
- 空中 Z 追擊。
- 空中 X 墜擊。
- Dash + Z 衝刺攻擊。
- Hit Combo、累積傷害顯示。
- Hit Stop、擊退、浮空、硬直、破甲、霸體。
- MP 自動回復與技能消耗。
- C/V/B 三技能 CD。

設計方向參考高速橫向動作 RPG 常見的「Command Combo + Skill Cancel + 空中追擊」思路，但技能名稱、角色、數值與實作為本專案自己的設計。

## 3. 四個職業

### 裂隙劍士
- 近戰傷害略高。
- 攻擊累積裂隙值。
- 元素換位可消耗裂隙值追加爆發。
- Q：裂隙爆發。

### 靈契召喚師
- 浮光狐自動鎖定附近敵人。
- Q 讓召喚物短時間高頻攻擊。
- 技能含靈矢、護盾治療、星獸狂熱。

### 百獸憑依者
- Q：狼 → 鷹 → 熊循環。
- 狼：高速與快速攻擊。
- 鷹：空戰、低落速、額外跳躍。
- 熊：高傷、霸體、重擊。

### 符文機巧師
- Q 部署炮台，最多 3 台。
- 磁軌衝擊為長距直線攻擊。
- 彈射平台提供垂直機動。
- 超載回路提高炮台射速。

## 4. 世界擴張

地圖寬度提升到 18,000px，分為八區：

1. 餘燼訓練庭
2. 霜水導渠
3. 風岩採掘帶
4. 百獸高架林
5. 明影資料庫
6. 引力機巧站
7. 十相崩裂區
8. 回路核心塔

加入大量高低差、落穴、移動平台、危險地形與元素機關。

## 5. 敵人與 NPC

敵人：史萊姆、弓手、盾兵、飛行蝠、砲塔、瞬移術士、巨像、Boss。

NPC：戰鬥教官、機巧匠、馭獸師、檔案員。

## 6. 2P Prototype

新增 `network.js`：

- 建立房間。
- 房間代碼。
- 加入房間。
- PeerJS DataConnection。
- 玩家位置 / 方向 / 職業 / HP 等狀態同步。
- Host / Guest 角色標記。

目前是展示級 prototype，不宣稱具備正式競技 netcode 的抗延遲能力。

## 7. 開發友善化

- `config.js` 集中數值與資料。
- `game.js` 依系統分段並加入繁體中文註解。
- `network.js` 完全獨立。
- 全鍵位可改。
- Console Debug API。
- 不依賴圖片素材即可運作。
