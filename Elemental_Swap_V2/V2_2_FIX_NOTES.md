# Elemental Swap V2.2｜可讀性、UI、戰鬥回饋修正版

這一版不是新增更多系統，而是先修正「玩家根本看不懂現在發生什麼」的基礎體驗。

## 這次確認到的兩個根本問題

### 1. `styles.css` 在上一個重建包遺失

`index.html` 本來有：

```html
<link rel="stylesheet" href="styles.css">
```

但實際資料夾沒有 `styles.css`。

結果瀏覽器用 Canvas 的預設尺寸顯示遊戲。遊戲世界的地面約在 y=710，玩家也出生在約 y=632，因此在預設很小的 Canvas 裡玩家幾乎完全不在可視區域。

這也是為什麼會同時發生：

- 看不到主角。
- HUD 像沒有排版。
- 遊戲區域很小。
- 元素列與操作資訊很難讀。

V2.2 已重新建立完整 `styles.css`。

### 2. 敵人的「名稱」與「AI 類型」混在同一個欄位

例如設定檔中的史萊姆：

```js
slime: {
  name: "裂膠史萊姆",
  type: "melee"
}
```

上一版建立敵人時卻只保留 `type: "slime"`，AI 又用：

```js
if (e.type === "melee") ...
```

兩邊永遠對不上。

V2.2 改成：

```js
e.type = "slime";   // 這是敵人種類，用來決定外觀與資料表
e.ai   = "melee";   // 這才是 AI 行為分類
```

因此現在史萊姆、弓手、蝙蝠、巨像等 AI 都能正確進入各自邏輯。

# V2.2 視覺與體驗修改

## 玩家辨識

玩家不再只是一個白色矩形。

現在有：

- 黑色粗外框。
- 職業專屬發光色。
- 發光腳底定位圈。
- 頭盔、面罩、胸口職業核心。
- 明確面向箭頭。
- 開場 `YOU / 玩家` 浮標。
- 新手教學期間 Canvas 內也會跟著角色顯示 `YOU / 玩家`。

玩家位置就算在複雜背景裡也應該能快速辨識。

## 新手安全區

出生點到世界 x=1180 之間為安全訓練區。

在這裡：

- 主動敵人不會鎖定玩家。
- 第一個練習目標改成「訓練傀儡」。
- 訓練傀儡完全不會攻擊。
- 黃色虛線顯示正式戰鬥區邊界。
- 玩家跨過邊界後敵人才開始進入警戒。

這避免「一開場還不知道哪個是自己就被打」。

## 五段新手引導

右上角會依照玩家進度顯示：

1. 用 A / D 找到並移動自己的角色。
2. 按 1 發射火元素。
3. 再按 1 完成第一次元素換位。
4. 對訓練傀儡輸入 Z → Z → X。
5. 越過安全線進入真正戰鬥區。

不是一次把二十個按鍵全部丟給玩家。

## 元素投射物大改

10 種元素不再只有不同顏色的圓球。

- 火：內外兩層火核。
- 冰：菱形冰晶。
- 雷：鋸齒閃電。
- 風：多層風弧。
- 岩：不規則岩塊。
- 水：液滴高光球。
- 光：八芒星。
- 影：黑核＋紫色雙環。
- 自然：葉片／種子形。
- 引力：黑核＋三層變動重力環。

所有元素都加入長軌跡。

同時整體降低飛行速度、放大彈體，讓玩家真的有時間看到投射物飛出去。

如果投射物仍可以當作換位錨點，頭上會直接標：

```text
1 再按 ↔
```

不必自己記「我剛剛到底有沒有留下火錨點」。

## 元素命中回饋

敵人被打中後會直接顯示狀態文字，例如：

- `火 燃燒`
- `冰 冰緩`
- `雷 暈眩`
- `雷 導電暴擊`
- `風 強制擊飛`
- `岩 破甲`
- `水 濕潤`
- `光 顯形／淨化`
- `影 詛咒`
- `藤 纏根`
- `引 引力拉扯`

敵人有元素標記時還會顯示：

```text
火｜再按 1 換位
```

## 元素 HUD

底部十元素列現在會顯示三種狀態：

### 選取／最近發射

元素格突出發光。

### 場上有錨點

顯示：

```text
再按＝換位
```

### 有敵人被這個元素標記

顯示：

```text
敵人已標記
```

中間資訊列還會告訴玩家目前元素的用途，若已有可交換目標會直接變成：

```text
目前有換位目標｜再按 1 立即交換
```

## 敵人辨識

不同敵人現在使用不同剪影，不再全部是一樣的色塊：

- 史萊姆：圓弧軟體。
- 弓手：人形＋弓。
- 盾兵：大型盾牌。
- 蝙蝠：左右翼。
- 砲座：底座＋砲管。
- 術士：三角斗篷＋魔法球。
- 巨像：大型石軀＋發光核心。
- Boss：大型裝甲與頭冠。
- 訓練傀儡：藍色準星框。

靠近敵人時會顯示名稱與血條。

## 威脅提示

真正進入戰鬥後：

- 敵人鎖定玩家時頭上出現紅色 `!`。
- 右上角威脅 HUD 顯示最近敵人的名稱、距離與方向。
- 如果敵人在畫面外，左右邊緣會顯示紅色箭頭、敵人名稱與距離。
- 遠距攻擊不是生成後立刻飛，而是先有約 0.42 秒蓄力警示。
- 敵方子彈改成高亮白核＋紅色尾跡。
- 玩家受傷時有紅色畫面邊緣閃爍。
- 中央訊息明確告訴你「哪一個敵人造成多少傷害」。

## HUD 重做

左上：

- 職業。
- 職業資源。
- HP。
- MP。

正上：

- 區域名稱。
- Combo Hit / Damage。

右上：

- 新手／任務目標。
- SAFE / CLEAR / DANGER 威脅狀態。

下方：

- 最近元素詳細資訊。
- Z / X / C / V / B / Q 技能列。
- 技能 MP 消耗／Cooldown。
- 十元素狀態列。

世界畫面整體向上取景，底部 HUD 不會直接蓋住主角。

# V2.2 程式修正

除了體驗問題，也補了以下程式修正：

- 修正 `styles.css` 遺失。
- 修正敵人 AI archetype 對應錯誤。
- 修正死掉敵人的 hurt timer 不再遞減、可能長期殘留的問題。
- 敵人 AI 加入 awareness range，不會隔超遠距離運算與攻擊。
- 主動敵人必須進入可視區附近才會取得 aggro。
- 遠距敵人增加 attack warmup。
- 新增安全區戰鬥 gate。
- 新增 tutorial state machine。
- 新增元素投射物 trail 資料。
- 新增 `shots` 與 `meleeHits` 統計，供教學流程判斷。
- Canvas 世界增加固定 Y camera offset，替底部戰鬥 HUD 留出空間。

# 建議你先這樣測

1. 打開 `index.html`。
2. 確認畫面中央偏左能立即看到發光角色與 `YOU / 玩家`。
3. 站著 10 秒，不應該掉任何 HP。
4. A / D 移動。
5. 按 `1`，確認能明顯看到大型火球與長尾跡。
6. 趁火球仍在場上再按 `1`，確認位置交換。
7. 到藍色訓練傀儡旁按 `Z → Z → X`。
8. 越過黃色虛線。
9. 確認敵人開始有紅色 `!`。
10. 讓弓手射擊，確認先看到蓄力圈，再看到紅色尾跡子彈。
11. 故意被打一次，確認會顯示傷害來源。

如果上述 11 項都成立，這一版至少已經解決「看不到自己、不知道誰在打我、看不到子彈」三個最嚴重的 UX 問題。
